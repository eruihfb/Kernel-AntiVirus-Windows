# 🛡️ Kernel Antivirus for Windows

Real-time download scanner, multi-folder daily scanner, quarantine vault, and kv terminal CLI for Windows.

## Setup
1. Get a free API key from VirusTotal.
2. Open Command Prompt (cmd) or PowerShell, `cd ` into the downloaded folder, and run:
   `install.bat`
3. Paste your API key when prompted, then open a new terminal window and type `python antivirus.py` (or use your configured kv alias) to check available commands.[cite: 1]
